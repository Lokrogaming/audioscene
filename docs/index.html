Was ist AudioScene?

Genau wie OBS, nur ohne Videobild. Unten die vier Bausteine – klicke dich durch:

Quellen = alles, was Ton macht. Unten im Dock auf + klicken:
  • 🖥️ Anwendungs-Audioaufnahme: Nimmt eine App auf. Windows fragt: Fenster wählen + „Systemaudio teilen“ anhaken.
  • 🎤 Eingabegerät: Mikrofon / Headset aus der Liste wählen.
  • 🔈 Ausgabegerät: Alles, was du hörst (Loopback). MVP nutzt denselben System-Dialog, natives WASAPI-Loopback folgt.
Mixer = Lautstärke pro Quelle. Jede Quelle bekommt einen Fader, Mute-Button und Live-VU (grün/gelb/rot wie in OBS). Alles läuft in einen Master-Bus – genau der wird aufgenommen. Rote VUs = zu laut, runterziehen.
Aufnahme = ein Button. Rechts in Steuerung auf ⏺ Aufnahme starten oder F9. Oben erscheint ● REC 00:00 + Timer. Stoppen → Speichern-Dialog im Aufnahme-Ordner.
Einstellungen = wie OBS. Unter ⚙ Einstellungen: Ausgabe (Ordner, Format WebM/WAV), Audio (48 kHz, Stereo/Mono), Aufnahme (Bitrate 64–320 kbps). Höhere Bitrate = besser, aber größere Datei.

Schritt 1: Quellen hinzufügen – wie in OBS

🖥️

Anwendungs-Audioaufnahme

Für Spotify, YouTube im Browser, Discord, Spiele. So geht's:

  1. Bei Quellen auf + → Anwendungs-Audio
  2. Namen geben, z. B. „Spotify“
  3. Im Windows-Dialog Fenster/Tab wählen
  4. Wichtig: Haken bei Systemaudio / Tab-Audio teilen

Video-Track wird automatisch verworfen – es bleibt nur Audio.

🎤

Eingabegerät (Mikrofon)

Headset, USB-Mic, Interface:

  1. Auf + → Eingabegerät
  2. Gerät aus Dropdown wählen
  3. Beim ersten Mal Mic-Erlaubnis bestätigen
  4. Im Mixer Pegel prüfen (grün = gut)

Tipp: Windows-Sound → Eingabe-Lautstärke auf 80–90 %.

🔈

Ausgabegerät (System-Sound)

Nimmt auf, was aus Lautsprecher/Kopfhörer kommt:

  1. Auf + → Ausgabegerät
  2. System-Dialog bestätigen
  3. Parallel App-Audio vermeiden (doppelt!)

Nativ per WASAPI ohne Dialog ist für v0.2 geplant.

Schritt 2: Mixer verstehen

  • Fader: Lautstärke je Quelle (0–100 %). Doppelklick = 100 %.
  • 🔊 / 🔇: Mute pro Quelle. Auge in Quellenliste zeigt Status.
  • VU-Meter: grün ok, gelb laut, rot übersteuert.
  • Wellenform oben: Zeigt den Master. Rot = REC läuft, blau = bereit.
  • Reihenfolge: Mit ▲▼ sortieren (nur Optik, kein Einfluss auf Sound).

Interaktive Mini-Demo (nur Deko – echte Pegel in der App)

Schritt 3: Aufnehmen – ein Button

  1. Mind. 1 Quelle hinzufügen (sonst meckert die App).
  2. Rechts auf ⏺ Aufnahme starten oder F9.
  3. Oben läuft ● REC + Timer, Wellenform wird rot.
  4. Auf ⏹ Stoppen → Speichern-Dialog (Standard: Aufnahme-Ordner).
  5. Dateiname z. B. AudioScene_2026-10-07_15-30-00.webm
  6. Mit 📁 Aufnahmen öffnen direkt zum Ordner springen.
Steuerung (wie OBS)
⏺ Aufnahme starten
⏹ Stoppen
⚙ Einstellungen
📁 Aufnahmen öffnen

Hotkey F9 lässt sich in den Einstellungen ändern (Anzeige).

Schritt 4: Einstellungen – Bitrate & Co.

Ausgabe

  • Ordner: Standard Musik/AudioScene, änderbar via Durchsuchen.
  • Format: WebM (Opus, klein) oder WAV (riesig, verlustfrei).
  • Dateiname: Vorlage mit Datum/Zeit.

Audio

  • 48 kHz Stereo = OBS-Standard, passt fast immer.
  • 44,1 kHz nur für reine CD-/Musik-Projekte.
  • Mono halbiert Größe, ideal für Sprache.

Aufnahme (Bitrate)

64 kbpsSprache, mini
128 kbpsStandard, ok
192 kbps ★guter Musik-Mix
320 kbpsmax, große Datei

Faustregel: Podcast 128, Musik 192–256.

Bitraten-Rechner: Wie groß wird die Datei? (Bitrate × Sekunden ÷ 8)
Min ≈ 9,6 MB

Speicherort: Warum „Musik“ automatisch geht

Windows heißt je nach Sprache anders: Deutsch „Musik“, Englisch „Music“. AudioScene rät nicht, sondern fragt Windows direkt:

  • Beim ersten Start: app.getPath('music') → echter Musik-Ordner
  • Darin wird AudioScene/ erstellt
  • Beispiel DE: C:\Users\Du\Musik\AudioScene
  • Beispiel EN: C:\Users\You\Music\AudioScene
  • Eigener Pfad jederzeit in Einstellungen änderbar
kopiert ✓ 
const music = app.getPath('music');
// DE → C:\Users\Du\Musik
// EN → C:\Users\You\Music
const dir = path.join(music, 'AudioScene');
fs.mkdirSync(dir, { recursive: true });

FAQ

Absicht: Die App nimmt auf, spielt aber nicht live zurück (kein Feedback/Echo). Deine Datei enthält alles. Monitoring folgt in v0.2.
Im System-Dialog unbedingt Systemaudio / Tab-Audio teilen anhaken. Ohne Haken kommt nur Video (wird verworfen) und die App warnt.
WebM (Opus) für Alltag: klein, gut. WAV nur wenn du später mastern willst – 10 Min Stereo ≈ 100 MB. MP3/FLAC via FFmpeg ist geplant.
Standard: Musik/AudioScene (DE: Musik, EN: Music). In der App auf 📁 Aufnahmen öffnen klicken – geht immer, egal welche Sprache.
Noch nicht in v0.1. Roadmap: Gate, Kompressor, EQ pro Quelle – wie OBS-Filter.
